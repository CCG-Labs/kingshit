Why isometric tiles look like a board game — and what fixes it

The core problem: hard diamond edges are visible on every tile. Each technique below attacks this differently.

Current — the board game problem

Per-tile random color variation

Each tile picks a random hue shift. Nearby tiles look unrelated. The diamond grid is perfectly visible because every edge is a hard color boundary.

Better — smooth noise color patches

Perlin/fractal noise for color

Color varies slowly using noise, so nearby tiles share a color family — like real terrain. The grid is still there but the eye reads "patches" not "tiles".

Much better — break the decoration grid

Non-aligned, size-varied decorations

Trees/rocks placed at random sub-tile offsets with random sizes. The decoration layer stops revealing the underlying grid. Used by Stardew Valley, AoE, etc.

Best — hide the grid entirely

Terrain splatting overlay

After drawing tiles, paint large organic blobs on a second canvas layer. The blobs define terrain regions independent of the grid. The tile edges are hidden under the paint layer.
